# 三道题、五个模型：一次横评的原始材料

这个仓库放的是一次模型横评的全部原始材料：三道题，五个模型（其中一个是 2026-11-12 追加的），每个模型每道题只跑一次，交卷之后没有人工返工。配套的文章发在公众号上（链接待填）。

## 目录结构

```
tasks/     三道题的题目原文，和题目要用的输入文件
models/    五个模型交出来的原始答案，以及它们自己写的交付说明
scoring/   六个方面的分数表、总榜，和 11 张首屏截图
```

## 三道题

**数字孪生引擎开发。** 每个模型都会拿到一张 SVG 平面图，任务是解析这张图，生成一个对应的数字孪生场景。引擎要提供不同类型的现成家具——办公桌、办公椅、文件柜这些，模型可以在场景里拖动它们，摆放位置。最后引擎要能把设计好的房间导出成模型文件，这个文件要能在 Unity 和 UE5 里用起来：Unity 原生认 obj 和 fbx，glb 要先装 glTFast；UE5 原生不认 glTF，要装插件或者用 Datasmith。题目里还有两条加分项：家具穿墙或者叠放的时候给个提示；换一张新图纸不用刷新页面。这一题考的是模型的工具调用能力和格式规范。

题目原文在 `tasks/task-1-brief.md`。

**后端代码修复。** 一份甲方跑路、订单模块只做了一半的后端代码。我在里面手动埋了 8 类订单服务最常见的问题，要求模型判断这段代码能不能交付，并且给出修改意见和修改计划。这一题考的是模型看后端代码的判断力，以及它会不会瞎报。

题目原文在 `tasks/task-2-brief.md`。

**前端场景渲染。** 模型在火箭发射和火山喷发里二选一，要求渲染出足够的粒子、烟雾这些特效。为了压榨模型的能力，题目要求打开页面 10 秒之内就出现最精彩的那一幕，不许等人操作。这一题是邀请方点名要的。

题目原文在 `tasks/task-3-brief.md`。

题目原文里写的是评测当时的相对路径（每个模型目录下面有一份 `_shared/`），仓库里把三个输入文件统一放在了 `tasks/assets/` 下面。

## 五个模型

参加测试的有五个模型：千问4预览版、Opus 5.5、DeepSeek V4.1 Flash 1017、Grok-bot 4.7，以及 2026-11-12 追加的千问4 线上预览版。测评用的是同一套 Prompt、同一个运行环境，每道题只执行一次，分别考察模型的工程能力、后端能力和前端能力。

- **千问4预览版。** 总分 86.0，排在第三。渲染题第一，是最初四个模型里唯一选了火山的。
- **Opus 5.5。** 总分 86.3，排在第二。图纸题和后端题都是最初四家最强，渲染题因为箭体飞出画面丢了分。它的页面通过 CDN 加载 three.js，打开需要联网。
- **DeepSeek V4.1 Flash 1017。** 总分 84.6，排在第四。交付最稳，问题定位到哪一行的标注最准。
- **Grok-bot 4.7。** 总分 78.7，排在第五。第一眼最有设计感，但图纸题和后端题的完成度、工程结构都是五家最低。
- **千问4 线上预览版（2026-11-12 追加）。** 总分 88.0，排在第一。图纸题 89.5、后端题 92.5、渲染题 81.5；和早先的千问4 预览版比，前两题更强、渲染题更弱。

`models/` 下面一个模型一个目录，五个目录的结构一样：

- `answers/1/`：图纸题的答案，是一个可以直接打开的网页。
- `answers/2/`：后端题的答案，包括 `FINDINGS.md`（体检报告）和 `patched/orders.js`（改好的代码）。
- `answers/3/`：渲染题的答案，是一个可以直接打开的网页。
- `DELIVERY.md`：这个模型自己写的交付说明，里面包括它承认没做完的部分。

网页里带的 `out.glb`、`out.obj`、`out.mtl` 是模型自己导出的样例文件。

## 分数怎么来的

每道题满分 100 分，分数按六个方面计算：完成度、一次成功率、工程结构、界面与呈现、时间、资源消耗。三道题里，这六个方面的分值不一样，具体的分值表和每个模型的分数在 `scoring/scores.md` 里。

总分是把三道题的分数按 4:3:3 的比例加起来算的。

总榜：千问4线上预览版拿到 88.0 分，Opus 5.5 拿到 86.3 分，千问4预览版拿到 86.0 分，DeepSeek V4.1 拿到 84.6 分，Grok-bot 4.7 拿到 78.7 分。

## 追加：千问4 线上预览版（2026-11-12）

2026-11-12 用同一套三道题、同一套评分标准，单独复测了千问4 线上预览版。三题 89.5 / 92.5 / 81.5，加权 88.0。原始答案在 `models/qwen4-online-preview/`，评分明细在 `scoring/qwen4-online-preview.md`，补拍的三张首屏截图在 `scoring/screenshots/` 下，文件名以 `qwen4-online-preview` 开头。

这一轮只测一个模型；上面四家的分数是原来那一批，没有重算。对比来看，线上预览版在图纸题和后端题上比预览版分别高了 9.5 和 3.5 分，渲染题低了 9.5 分。
## 边界

- 这些分数是我一个人打的主观分，题目是我自己出的，每道题只让模型跑了一次，六个方面各占多少分也是我定的。它更像一份认真的试用记录，不是专业测评机构做的那种测试。
- 这次测试是受邀完成的：邀请方提供了千问4预览版的提前访问，并且审阅了我在公众号发布的文章。本仓库只放原始材料和分数，不把结论放在这里。
- 截图都是首屏的静态图，渲染类的产出动起来之后差别更大。
